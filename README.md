# Two-Stage Miller Compensated CMOS Operational Amplifier
This project involved the design of a two-stage Miller compensated CMOS operational amplifier in 90nm CMOS technology, implemented and simulated using Cadence Virtuoso. The first stage was designed as a PMOS differential input pair amplifier with an active current-mirror load, while the second stage was implemented as a common-source NMOS amplifier to provide additional gain and drive the output load. To ensure frequency stability, a nulling resistor (Rc) was connected in series with the Miller compensation capacitor (Cc), which shifted the right-half-plane zero to the left-half plane and significantly improved the phase margin.
